Публичный контракт команды `sync` перенесён; Python сохраняется как эталон
для воспроизводимых проверок.

- Исходный Python suite: 386 тестов прошли.
- На одной локальной копии каталога InsonusK/ai-skills обе реализации

  различий содержимого не обнаружено. Managed-маркеры сравниваются отдельно:
  формат отпечатка намеренно изменён.
- Результат сравнения относится к этому каталогу и набору сценариев;
  это не доказательство идентичности на любых входах.

## Сохранённые особенности

| Область | Поведение |
| --- | --- |
| Query tags | Иерархия и wildcard следуют Python, включая совпадение части query |
| Link labels | Inline code внутри подписи исключает ссылку из проверки |
| Known owner | Путь внутри выбранного directory skill разрешается по принадлежности даже при отсутствии файла |
| Link output | Путь от каталога конфигурации, а не от выходного Markdown |
| Missing subpath | Пустой выбор, не ошибка; при удалении orphans это может удалить управляемые скилы |
| Links in examples | Исключение проверки не исключает копирование файлов |
| External attachments | Копируются без рекурсивного обхода их собственных ссылок |

## Осознанные отличия

| Область | Go |
| --- | --- |
| Настройки Python, не подключённые к pipeline | Применяются `dry_run`, `on_conflict`, link `skip_folder` и `source.name` |
| Name override | Требует ровно один выбранный скил |
| Managed hash | SHA-256 выходных файлов, режимов и вложений; версия преобразования `go-2` |
| Старый Python marker | Скил считается управляемым, первый запуск Go обновляет его |
| Личный каталог / файл / symlink | Выбранное имя, уже занятое неуправляемым объектом, блокирует синхронизацию |
| Paths | Запрещены выход за корень источника, symlink-цели и пересекающиеся цели |
| Archive fallback | Принимает regular files/dirs, запрещает links и traversal; лимит 512 MiB распакованных файлов |
| Validation failure | Блокирует применение всех целей |
| YAML | При Claude/name-преобразовании порядок ключей, переносы и отступы могут отличаться |
| CPU profile | Go pprof вместо cProfile |
| Console | Текстовый план create/update/skip/remove и slog; оформление не копирует Python |
| Version | Добавлен `--version`; release-значение из VERSION |
| Link-adapter gating (исправление в Go) | До исправления `Planner.Plan` переписывал ссылки для любой цели, у которой есть файлы со ссылками, независимо от `target.adapters`; теперь переписывание применяется только при наличии `link-adapter` в объединённом списке адаптеров цели, как и было задокументировано в `docs/api/reference.md`. На текущий `ai-skills.yaml` репозитория поведение не меняется, так как `link-adapter` уже входит в `for_each.adapters` для каждой цели |
| Дедупликация источников (улучшение только в Go) | `sourcing.Manager` кеширует полученный `Repository` по `SourceKey` (тип+путь+ветка): два `sources:` с одним и тем же источником, но разными `subpath`/`tags`, скачиваются/клонируются один раз, а не по разу на запись. Python re-fetch-ит источник для каждой записи `sources:` независимо от совпадения type/path/tree |

Общие внешние вложения влияют на хеш каждого скила; это может вызвать
лишние обновления, но не пропуск изменившихся вложений. Управление orphans
относится к каталогам скилов с маркером. Общая папка `files/` резервируется
для CLI: существующие вложения обновляются, старые не удаляются автоматически.

## Как повторить сравнение

Используйте отдельный временный каталог для каждой реализации и одну
локальную копию источника. В двух конфигурациях меняются только пути целей.

```sh
make build
./bin/aism sync --config /tmp/go-fixture.yaml
PYTHONPATH=deprecated/ai-skill-manager/src .venv/bin/python -c 'from ai_skill_manager.cli import main; main()' sync --config /tmp/python-fixture.yaml
```

Сравнивайте список относительных путей без `.ai-skills-managed`,
нормализуйте префиксы целей в ссылках, декодируйте YAML frontmatter и
секцию Metadata. Остальное тело Markdown и бинарные вложения должны совпасть.
Для Python нужны зависимости из submodule; новый CLI их не использует.
